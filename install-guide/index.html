腳本工廠＋剪接招式庫

開始前，準備三樣

一台電腦Mac 或 Windows 都可以。只用手機、網頁版的不適合。
Claude Pro你自己的付費帳號，月費 20 美金，約台幣 650。
訂閱 300每月 300 元，腳本工廠＋招式庫一起拿。

訂閱在 Portaly：portaly.cc/sam.reels.tw/support，信用卡每月自動扣款，隨時可退訂（退訂是停下期扣款，當月照常用到期滿）。

付款之後會收到

  1. 1

    一封信：腳本工廠開始使用包

    一天內寄到你付款的 Email。裡面有說明書、你的專屬網址、Claude 桌面版安裝說明。專屬網址只給你一個人用。

  2. 2

    招式庫要你自己私訊來拿

    照下面「剪接招式庫」那段做。

第一套｜約 10 分鐘

四步裝好腳本工廠

  1. 1

    下載 Claude 桌面版

    到 claude.com/download 下載安裝，登入你的 Claude Pro 帳號。

  2. 2

    加連接器

    設定 → 連接器 → 新增自訂連接器。名稱填「腳本工廠」，網址貼信裡的專屬網址。

  3. 3

    打開 Code 分頁，選一個資料夾

    視窗上方點 Code，選一個資料夾（例如在桌面新建一個「腳本工廠」）。

  4. 4

    打一句話

    打 幫我建腳本工廠工作台，Claude 會問你要不要允許，看清楚是你選的那個資料夾、是腳本工廠，再按允許。工作台開出來，先答三題就能出題。

第二套

三步接上剪接招式庫

  1. 1

    IG 私訊 @sam.reels.tw

    附上你付款的 Email 和 GitHub 帳號。白天通常 1 小時內回你。

  2. 2

    收邀請、拿資料夾

    有 GitHub：收到邀請信按接受，把招式庫下載到電腦。沒有 GitHub 不用去註冊，私訊說一聲，我們改給壓縮檔，解壓縮放在桌面就好。

  3. 3

    交給 Claude

    在 Code 分頁選招式庫那個資料夾，打開資料夾裡的說明，把標示的那段開工文字複製貼給 Claude。

之後要剪片：在招式庫資料夾的 Code 分頁說 開始剪片，丟你的影片。它會一步一步問你，從逐字稿、粗剪、挑風格一路帶你做到成片。音效它會列出來附下載頁，要你自己點下載。

新訂閱送 1 支示範片（每月前 15 位）

在同一個 IG 私訊，附上你的口播影片雲端連結（1–3 分鐘）。

我們先回你有沒有排到。收到影片 7 天內交 1 分鐘初稿，可以改一輪，另附設定檔，讓你下一支照著剪。

拿到示範片後就不能退款。
