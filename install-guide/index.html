第一套｜約 10 分鐘

六步裝好腳本工廠

1

下載 Claude 桌面版

用瀏覽器打開 claude.com/download，按下載。裝好打開，登入你的 Claude Pro 帳號。還沒有帳號：先到 claude.ai 註冊，在 Settings → Billing 升級成 Pro，再用同一組帳號登入桌面版。

2

打開「新增自訂連接器」

  • 左邊選單點 Customize
  • 上面選 Connectors
  • 右上按 ＋ Add → Add custom connector
3

填名稱、貼專屬網址

  • Name（名稱）填 腳本工廠
  • MCP server URL（網址）：打開「你的專屬網址.txt」，整行複製貼上
  • 按 Continue，其他都不用填
4

切到 Code，選一個資料夾

  • 左上角點 </> 圖示，左上角的字會變成 Code
  • 輸入框下面按資料夾那顆鈕，選一個資料夾。例如先在桌面新建「腳本工廠」資料夾再選它
5

打一句話，看清楚再按允許

在輸入框打 幫我建腳本工廠工作台 送出。Claude 會問能不能用腳本工廠、能不能發布工作台，看清楚寫的是腳本工廠，再按 Allow once 或 Always allow。

允許視窗是照真畫面比例畫的示意，實際字可能略有不同；按鈕寫 Allow、Always allow 或「允許」都一樣。

6

工作台出來就裝好了

右邊會打開工作台。先答三題，按「出第一輪題」，通常約 2 分鐘題目就進提案櫃（看 Claude 用量和網路）。

畫面是示範用的假資料（健身教練）。

第二套

四步接上剪接招式庫

1

IG 私訊 @sam.reels.tw

附上你付款的 Email 和 GitHub 帳號。沒有 GitHub 不用去註冊，說一聲就好，我們改給壓縮檔。白天通常 1 小時內回你。

2

收邀請信，按接受

有 GitHub 的人會收到 GitHub 寄的邀請信，按 Accept invitation。拿壓縮檔的人跳過這步。

3

把招式庫放到電腦

在招式庫頁面按綠色 Code → Download ZIP，下載後解壓縮，放在桌面。拿壓縮檔的人直接解壓縮放桌面。解壓縮：Mac 點兩下；Windows 按右鍵選「全部解壓縮」。

4

在 Code 選招式庫資料夾，貼使用提示詞

Claude 左上角點 </> 切到 Code，輸入框下面的資料夾選剛剛的招式庫，要選點進去直接看到「型錄.html」的那一層。再打開資料夾裡的「給Claude的使用提示詞.md」，整段複製貼進輸入框，送出。

之後要剪片

在招式庫資料夾的 Code 分頁說 開始剪片，把影片拖進去。它會一步一步問你，從逐字稿、粗剪、挑風格一路帶你做到成片。音效它會列出來附下載頁，要你自己點下載。

新訂閱送 1 支示範片（每月前 15 位）

一人限一次，續訂不再送，名額照付款先後算。付款前可 LINE 問還有沒有名額；滿了照樣能訂，只是沒有示範片。

在同一個 IG 私訊，附上你的口播影片雲端連結（1–3 分鐘）。

我們先回你有沒有排到。收到影片 7 天內交 1 分鐘初稿，可以改一輪、改完 3 天內交，另附設定檔，讓你下一支照著剪。

拿到示範片後就不能退款，交片前會再提醒你一次。
